# MagnolIA Nexus · descargas

Instaladores oficiales de **MagnolIA Nexus**, la aplicación de escritorio de MagnolIA para macOS y Windows.
El código vive en un repositorio privado; aquí solo se publican las versiones.

Descarga siempre la última versión:

- macOS (Universal, macOS 13 o superior): [MagnolIA-Nexus-macOS.dmg](https://github.com/Dudulawl/magnolia-nexus-releases/releases/latest/download/MagnolIA-Nexus-macOS.dmg)
- Windows (10/11, 64 bits): [MagnolIA-Nexus-Windows-Setup.exe](https://github.com/Dudulawl/magnolia-nexus-releases/releases/latest/download/MagnolIA-Nexus-Windows-Setup.exe)

Más información y requisitos en [magnoliaone.ai/productos](https://magnolia.ai/productos).

Nexus busca actualizaciones por sí solo (y desde Ajustes › Actualizaciones) leyendo el `latest.json`
de la última release; cada descarga va firmada y se verifica antes de instalarse.
